# 铜印房产 · 带看与佣金归属系统

面向房产经纪团队的内部业务系统：登记房源、客户、带看经纪人、预约时间与带看签到；
客户在保护期内成交时，按**已签署的团队规则版本**给出佣金归属候选，主管裁决；
每次带看的经纪人/客户签字、客户确认等证据完整留存。

纯 Python 标准库实现（`http.server` + `sqlite3`），**零第三方依赖**。

## 一条命令启动

```bash
./run.sh            # 默认端口 8000
./run.sh 8124       # 指定端口
```

启动时自动重建演示库（含多经纪人冲突样例）。打开 <http://localhost:8000>，
在右上角切换操作身份（主管为 **陈岚 / 孙岩**）。

也可分步运行：

```bash
python3 -m app.seed --reset    # 建库 + 种子
python3 -m app.server 8000     # 启动
python3 -m unittest tests.test_domain -v   # 测试
```

## 判定规则（需求逐条对应）

| 场景 | 处理 |
|---|---|
| 重复客户 | 手机号/证件号为强标识，留资命中既有客户即**合并**，不另建档案；姓名重名允许并存，检索页提示人工核对 |
| 同一天多名经纪人带看 | 首看日多名经纪人并列候选；含跨店时门店先留存（v2 为 25%），余额均分；自动生成待裁决争议 |
| 客户自行到店 | 记为无经纪人带看，**不产生保护期**；成交时佣金归房源方门店 |
| 跨门店协作 | 经纪人需有跨店权限且显式确认协作登记；独家跨店按 v2 门店 35% / 协作经纪人 65% |
| 带看取消 | 未签到可取消；取消后释放当日登记键、可重新预约；**已签到不可取消** |
| 保护期结束后成交 | 保护期含到期日当天，次日失效；期外成交候选仅房源方门店，无需争议 |
| 经纪人自裁 | 主管角色才能裁决；主管本人是候选之一（利益相关）时被拒绝 |
| 裁决依据 | 必须锁定规则版本 + 每候选已签到且客户已确认 + 勾选“已核对”，否则拒绝 |
| 并发双记录 | 部分唯一索引 `ux_viewings_active`（客户+房源+经纪人+带看日，未取消）由 SQLite 裁决，第二个写入失败 |

### 规则版本化

- `2025-v1`（2025-01-01 生效）：保护期 30 天，独家首看 80%，跨店门店留 30%
- `2026-v2`（2026-09-01 生效）：保护期 60 天，独家首看 70%，跨店门店留 35%，同日多经纪人门店留 25%

保护期窗口在**首看日**即对经纪人确立（按首看日生效版本计天，新规则不改写既得保护期）；
分成比例按**成交日**生效版本计算；裁决锁定争议开案时的规则版本，页面全程显示版本号。

## 页面

- **工作台/检索**：房源（地址、区域）、客户（姓名/手机/证件，带去重提示）
- **房源页**：地址为标题，突出带看时间线（待签到/已签到/取消、跨店、客户确认），
  侧栏实时保护期提示、登记带看、登记成交
- **带看日历**：月视图，点击带看进入签到；取消删除线、已签到绿色
- **签到页**：手写签名板（Canvas，PNG 本地保存到 `data/signatures/`），
  经纪人 + 客户双签字、客户现场确认勾选
- **佣金争议页**：成交价、佣金总额、规则版本常驻可见；各候选经纪人的
  签到时间/签字图/客户确认**并列卡片**展示；主管填入份额（合计须 100%）并裁决，
  已裁决显示裁决主管、锁定规则、说明，不可改判
- **规则版本 / 短信记录**：版本明细；模拟短信只落 `sms_log` 并打印控制台

## 存储

所有写操作同时向 `events` 表追加一条事件（`viewing_scheduled / viewing_checked_in /
viewing_cancelled / deal_recorded / dispute_opened / dispute_decided / client_confirmed …`），
当前状态表便于查询，事件表保证裁决留痕与可回放。

```
app/db.py       表结构、连接、事件追加、幂等键
app/domain.py   去重、带看、签到、保护期、候选分成、争议裁决（全部规则）
app/sms.py      短信模拟适配器
app/server.py   http.server 路由与页面
app/seed.py     种子数据（含全部判定样例）
tests/test_domain.py  25 个测试：保护期边界/去重/跨店权限/裁决留痕/并发双记录等
```

界面为白底、深灰文字、少量铜色点缀，表格与证据卡片为主，无营销海报式区块。
